# Experiment design

Freeze before inference: 12 development and 36 evaluation cases, disjoint source groups, two local model revisions, one prompt, 0.6 NLI confidence threshold, seed 1729, two CPU threads. No model fitting or threshold search. Development is a diagnostic smoke evaluation, not a tuning exercise. Both judges see exactly the quoted passage and claim, never the reference label, rationale, category, or neighboring uncited source text.

The deterministic baseline recognizes exact complete sentences (case folded) and explicit `is not` / `are not` inversions. Everything else abstains. It does not infer contradiction from missing words and does not claim general semantic correctness. Quoted speech, inconsistent passages, and complex negation can fool these rules.

FLAN-T5-small uses greedy decoding, one beam, eight new tokens, and exact label parsing after whitespace and case normalization. Extra explanations, punctuation, unknown outputs, and empty outputs abstain. DeBERTa uses passage as premise and claim as hypothesis; indices 0/1/2 map to contradiction/entailment/neutral, checked against model config. Softmax maximum below 0.6 abstains. These probabilities are not calibrated reliability estimates. Inputs above 384 tokens fail rather than silently truncate.

Insufficient is a semantic class: neither the claim nor its denial follows. Abstain is a checker decision: the rule or judge declines classification. Class precision is TP / all predictions of that class; recall is TP / references of that class. Zero denominators produce JSON null, not zero. Accuracy counts abstentions as incorrect. Coverage is non-abstentions / all cases. Selective accuracy uses only non-abstained cases. Every metric is reported overall and within each phenomenon category, alongside integer confusion counts.

No significance test or broad superiority claim is supported by 12 evaluation passage groups. Three related claims per passage are dependent. This is a transparent fixture comparison, not a representative population sample. One duration per pair includes tokenization and inference, excludes model loading, and is not a latency benchmark or load test.

Reports bind source hashes, exact quotes, Unicode offsets, immutable GitHub line links, raw generated labels or NLI probabilities, predictions, model file SHA-256 digests, model revisions, package versions, machine identity, implementation revision, and UTC timestamps. Offline verification replays rules, parsing, prompt construction, source validation, completeness, and metrics. It cannot prove inference authenticity, human review, or model quality. Model file hashes are recorded, not downloaded again during replay. Trace files are incremental recovery evidence; reports are written only after every method finishes. Existing output directories are refused.
