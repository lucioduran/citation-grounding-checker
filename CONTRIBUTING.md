# Contributing

Use focused commits, English documentation, and regression tests. Keep the README section contract. Run Ruff, unit tests, coverage, and both report replay commands before proposing changes. Model downloads and inference are optional for ordinary contributions.

Do not overwrite recorded experiments or tune against evaluation outcomes. Put new experiments in new directories, disclose changed corpus or model settings, and record hardware and versions. Keep synthetic reference judgments distinct from independently reviewed human annotations. Never claim human review without attributable review records and consent.
